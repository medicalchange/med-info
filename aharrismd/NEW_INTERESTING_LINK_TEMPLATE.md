# Interesting Links Draft Template

Use this as a scratchpad when you want to collect a few links at once.
Each finished item should still become its own file inside `_interesting_links/`.

Copy one block below for each link you want to add:

```md
---
title: "Replace with article title"
date: 2026-06-10
link_url: "https://example.com/"
summary: "Replace with one or two sentences on why this is worth reading."
---
```

Example with multiple draft links:

```md
---
title: "First article title"
date: 2026-06-10
link_url: "https://example.com/first"
summary: "Why this first link is worth reading."
---

---
title: "Second article title"
date: 2026-06-10
link_url: "https://example.com/second"
summary: "Why this second link is worth reading."
---

---
title: "Third article title"
date: 2026-06-10
link_url: "https://example.com/third"
summary: "Why this third link is worth reading."
---
```

When you are ready to publish them:

1. Create one file per link in `_interesting_links/`
2. Name each file like `2026-06-10-short-title.md`
3. Paste one block into each file
4. Commit and push
